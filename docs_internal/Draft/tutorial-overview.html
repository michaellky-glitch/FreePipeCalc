Tutorial — FreePipeCalc Overview

How the interface is organised, what the two disciplines do, and the typical workflow for hydronic and plumbing systems.

FreePipeCalc · v0.18.2 · Read this first

FreePipeCalc draws a piping network, solves it, and produces a calculation sheet. The same interface serves two disciplines: Hydronic and Plumbing. This overview explains the shared controls and then walks through each workflow.

1. Overview

1.1 Interface elements

The window has three main areas:

  • Top ribbon — always visible. File commands, mode selector, display overlays, and helpers.
  • Drawing canvas — the plan view where you place pipes, nodes, and equipment.
  • Bottom ribbon — changes with the current mode. This is where you pick the tool you want to place.

Tabs along the top switch between views: PIPING NETWORK, HYDRAULIC, THERMAL, and CALCULATION. PIPING NETWORK is where you build the model. The other tabs set data and read results.

NOTE:

Some ribbons hide when you open HYDRAULIC, THERMAL, or CALCULATION. The drawing toolbar is only available on PIPING NETWORK.

1.2 Disciplines

The discipline chip is at the top right of the window, next to the status chip. Pick the discipline before you start drawing.

HYDRONIC

Use Hydronic for heating and cooling water systems: chilled water, hot water heating, condenser water, primary and secondary loops. Hydronic uses the full Global Gradient Algorithm solver, supports thermal solves, controls, pumps with curves, and equipment such as chillers, boilers, heat exchangers, and air-handling units.

PLUMBING

Use Plumbing for domestic water, drainage, or sanitary systems. Fixtures are sized with fixture units (FU). The solver converts FU to flow with a Hunter curve or similar method, then sizes pipes and, if needed, booster pumps.

IMPORTANT:

Discipline changes the available tools, the solver, and the calculation sheet. Switching discipline after you have drawn parts of a system can remove or alter data. Set the discipline before you draw.

1.3 Modes

Modes are in the top ribbon. They change what the bottom ribbon does and how the solver behaves.

  • DESIGN — Build the system. You set required flows; the app sizes pipes and pump duty. This is where most modelling happens.
  • CONTROL — Add sensors and control links. Link a pump or control valve to a sensor so it follows a setpoint during simulation.
  • SIMULATE — Test the system with pump curves and actual pressures. Flow becomes a result, not an input. Static and dynamic sub-modes control whether the solver runs on every edit.
  • ANNOTATION — Prepare the drawing for printing: move labels, add detail lines, text boxes, and choose what tags to display.
SUGGESTION:

Start every model in DESIGN. Add the full geometry, check the calculation sheet, then switch to SIMULATE to test pump curves and controls.

1.4 Properties window and tools

Click any item on the canvas to open its properties panel. The panel shows every value that belongs to that item: size, length, flow, pressure, temperature, Kv, pump curve, insulation, and so on. Edits in the panel update the model immediately.

The TOOLS button in the top ribbon opens a floating helper window. It contains small calculators: pump curve fit, pipe velocity, friction loss, heat transfer, and critical insulation radius. These are reference tools; they do not change the model unless you copy a result into a field.

The exact buttons on the bottom ribbon depend on discipline and mode. Plumbing replaces some thermal buttons with fixture and drainage tools; SIMULATE replaces the design tools with run and inspect tools.

2.3 Show overlays

SHOW buttons colour the drawing by result. They are read-only. The most useful overlays are:

  • FLOW — pipe colour by flow rate. See where the water goes.
  • VELOCITY — pipe colour by velocity, compared to the velocity limit set on HYDRAULIC.
  • PRESSURE — node colour by gauge pressure.
  • TEMPERATURE — node colour by temperature after a thermal solve.

3. Hydronic workflow

The fastest way to learn Hydronic is to open the example file examples/Tutorial 01 - Basics.json. It contains a simple chilled-water loop with a source, pump, chiller, and air-handling unit. Use it as a reference while you read this section.

3.1 Place the source

Every hydronic network needs at least one source. A source sets the reference pressure and, if needed, the supply temperature. In the example, SRC-1 is a source at 0 kPa gauge. It is the low-pressure point that the pump works against.

To place one: switch to DESIGN, choose SOURCE from the bottom ribbon, and click on the canvas. Then set the supply pressure in the properties panel.

3.2 Draw the pipe loop

Use PIPE to draw segments between nodes. Start at the source, draw toward the pump, then through the equipment, and finally back to the source. Keep horizontal pipes on the plan; use RISER only for vertical changes between levels.

In the example the loop is:

  • SRC-1 → pipe → pump PMP-01 → pipe → chiller CHILLER-01 → pipe → AHU-01 → pipe → back to SRC-1.

Click the start node, then click the end node. The app creates the pipe and snaps it to the grid if snap is on.

SUGGESTION:

Draw the whole loop before you size anything. It is easier to see the topology when the geometry is complete.

3.3 Add heat source/sink and heat exchanger

Once the loop exists, add the thermal devices.

  • HEAT SOURCE/SINK — Use for equipment that holds a leaving temperature. In the example, CHILLER-01 is a heat source/sink that leaves the water at 6 °C. It removes heat from the loop.
  • HEAT EXCHANGER — Use for equipment that has a fixed duty. In the example, AHU-01 is a heat exchanger with a 100 kW load. It adds heat to the chilled-water loop, so the chiller must remove it.

Place each device on a pipe by selecting the device tool and clicking the pipe segment where it belongs. The app splits the pipe and inserts the device.

3.4 Connect and configure

Open each device's properties panel and set its design values:

  • Pump — Leave mode on Auto in DESIGN. The app calculates the head and flow required to serve the loop.
  • Chiller — Set the leaving temperature and the rated flow. The thermal solve uses these values.
  • AHU — Set the heat load and rated flow. Check that the sign (heating or cooling) matches what the fluid does.

Then set the fluid on the HYDRAULIC tab. The default is water at 20 °C with Hazen-Williams friction.

IMPORTANT:

Thermal sign convention matters. In the example, the AHU adds heat to the chilled water, so the chiller must remove the same amount. If the sign is wrong, the energy balance will not close and the temperatures will be implausible.

3.5 Solve and simulate

Click RUN SIMULATION in SIMULATE-STATIC mode, or switch to SIMULATE-DYNAMIC to solve on every edit. The solver calculates flow, pressure, velocity, and temperature around the loop.

Check the results:

  • Open CALCULATION to read the sheet. The index circuit is listed first; its pressure drop sets the pump duty.
  • Click SHOW > TEMPERATURE to see where the water warms up.
  • Open THERMAL to check the energy balance and temperature range.

4. Plumbing workflow

Plumbing uses fixture units to convert fixture groups into design flow. The workflow is similar to Hydronic but with different equipment and a different solver.

4.1 Draw pipes and fittings

Switch to DESIGN and draw the supply main, branches, and risers with PIPE and RISER. The app detects elbows and tees from the geometry and applies the equivalent-length or K-value table set on the HYDRAULIC tab.

Set the pipe schedule and nominal sizes on the HYDRAULIC tab first. You can override individual pipe sizes in their properties panels.

SUGGESTION:

Keep branches simple at first. A main with one branch and one fixture is enough to verify the FU-to-flow conversion before you add complexity.

4.2 Create a source

Place a SOURCE on the upstream end of the main. Set the available pressure at the source. If the building pressure is not enough, add a PUMP and set it to Auto. The pump will be sized to deliver the required pressure at the most disadvantaged fixture.

4.3 Add fixtures

Place fixtures as OUTFLOW terminals. In Plumbing, outflows are entered in fixture units, not L/s. The solver converts FU to flow using the method chosen in settings. Set the fixture unit value for each terminal in its properties panel.

4.4 Simulate

Run the simulation. Because fixture units are a statistical representation of average demand, not simultaneous peak flow at every fixture, the results represent a design condition rather than an exact real-time event. For this reason, isolate fixtures or fixture groups when you want to examine specific operating cases, such as a single riser or one apartment unit.

IMPORTANT:

Fixture-unit flows are an averaged design load. They do not represent every fixture running at full bore at the same moment. When you simulate, isolate the fixtures or branches you want to study so the result matches the operating condition you are checking.
