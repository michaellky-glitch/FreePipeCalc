Tutorial — Hydronic — Piping Network

How to use the PIPING NETWORK tab in Hydronic discipline. Top ribbon and bottom ribbon, group by group.

Hydronic discipline · PIPING NETWORK tab · v0.18.2 · Read this first.

PIPING NETWORK is where you draw the system. Top ribbon stays the same. Bottom ribbon changes with the mode. Each mock-up below outlines one group. Read the description under it.

NOTE:

Orange outline = the group in focus. Other groups stay dim. Text below tells you what each button does. Use ASD-STE100 style: short sentences, one idea at a time.

IMPORTANT:

Set discipline to Hydronic with the chip at the top right (beside the status chip). Hydronic uses the full solver (Global Gradient Algorithm), thermal, and controls. If you see "Plumbing", switch it before you start.

1. Overview

PIPING NETWORK has two rows:

  • Top row — file, mode, show, misc. Always visible.
  • Bottom row — tools for the current mode. Only this row changes.

Top row answers "Where am I and what do I see?" Bottom row answers "What do I place?"

2. Top ribbon

All four groups sit in one row. The label above each group (FILE, MODE, SHOW, MISC) tells you its function.

2.1 FILE outlined

FILE — manage the file and undo.

  • NEW — Create a new model. Unsaved data is lost. Save first if you need it.
  • SAVE — Save the model to a .pnet.json file. Save often.
  • LOAD — Open a saved file. The app checks the file version on load.
  • PRINT — Print the drawing or the calculation sheet. Choice is automatic by tab.
  • REPAIR — Fix damaged tags. Visible only when the app finds a damaged tag. Click it when it appears.
  • DXF — Export geometry as DXF. Experimental. Check the file in CAD.
  • ↶ Undo (Ctrl+Z) — Undo the last change. Up to 60 steps.
  • ↷ Redo (Ctrl+Shift+Z) — Redo the undone change.

MODE — select what you do. Mode also sets the bottom ribbon.

  • DESIGN — Draw the system. You set required flow at outflows. The app sizes pipes and pump duty.
  • CONTROL — Place sensors and control links. This mode does not change the calculation mode. Use it to tune control while you simulate.
  • SIMULATE — Test the system. Pump curve is input. Flow is result. Use with STATIC or DYNAMIC sub-mode.
  • ANNOTATION — Prepare the drawing for print. Move labels, add detail lines, add text boxes.

DESIGN and SIMULATE also set the calculation mode. CONTROL and ANNOTATION keep the current calculation mode.

SHOW — change what is visible. No change to the model. Works in all modes.

  • LINKS — Show or hide control links on the drawing.
  • FLOW — Colour pipes by flow rate. High flow = strong colour.
  • VELOCITY — Colour pipes by velocity. Compares against the velocity limit.
  • PRESSURE — Colour nodes by gauge pressure.
  • TEMPERATURE — Colour nodes by temperature. Needs a thermal solve.

These are overlays. They help you read the result. They do not change it.

MISC — helpers.

  • TOOLS — Open the tools window. Contains: pump curve fit, pipe velocity, friction loss, heat transfer, critical radius. The window floats. The drawing stays visible behind it.
  • RENUMBER — Renumber nodes in flow order. Makes tags follow the water.
  • ⤢ Fit — Zoom to fit. Shows the full drawing in the view.

3. Bottom ribbon

Bottom ribbon shows tools for the current mode. DESIGN has five groups. Each mock-up below outlines one group.

DESIGN is the default

When you open PIPING NETWORK, you are in DESIGN. Start there. Add pipes, sources, outflows, equipment, and valves.

3.1 DESIGN > Edit outlined

EditSELECTCOPYPASTE PipePIPERISER HydraulicSOURCEOUTFLOWPUMPOTHER ThermalHEAT SOURCE/SINKHEAT EXCHANGER ValvesCONTROLISOLATIONCHECK

Edit — select and duplicate.

  • SELECT — Select and move items. Click an item to select it. Drag to move it. In SIMULATE-STATIC this tool only inspects.
  • COPY (Ctrl+C) — Copy the selection. Copies pipes, connected nodes, and links between them.
  • PASTE (Ctrl+V) — Place the copy. Press Tab to choose which end joins. Press R to rotate 90°.

3.2 DESIGN > Pipe outlined

EditSELECTCOPYPASTE PipePIPERISER HydraulicSOURCEOUTFLOWPUMPOTHER ThermalHEAT SOURCE/SINKHEAT EXCHANGER ValvesCONTROLISOLATIONCHECK

Pipe — draw the network.

  • PIPE — Draw a horizontal pipe. Click start node, then end node. Pipes are horizontal by rule. Only risers change level. Length is plan distance.
  • RISER — Create a vertical riser column. Join levels. Risers carry flow between floors. Size comes from the larger connected pipe unless you set it.

3.3 DESIGN > Hydraulic outlined

EditSELECTCOPYPASTE PipePIPERISER HydraulicSOURCEOUTFLOWPUMPOTHER ThermalHEAT SOURCE/SINKHEAT EXCHANGER ValvesCONTROLISOLATIONCHECK

Hydraulic — devices that move or use water.

  • SOURCE — Place a water source. Sets supply pressure and, if needed, supply temperature. You need at least one source for a valid network.
  • OUTFLOW — Place a terminal that requires flow. Set required flow and required pressure. In DESIGN, flow is input. In SIMULATE, flow is result via Q = K·√P.
  • PUMP — Place a pump. In DESIGN-Auto, duty is result. In SIMULATE, curve is input. Set speed or link to a sensor for control.
  • OTHER (adiabatic) — Place equipment with pressure drop only. No thermal effect. Use for strainer, filter, meter.

3.4 DESIGN > Thermal outlined

EditSELECTCOPYPASTE PipePIPERISER HydraulicSOURCEOUTFLOWPUMPOTHER ThermalHEAT SOURCE/SINKHEAT EXCHANGER ValvesCONTROLISOLATIONCHECK

Thermal — devices that add or remove heat. Thermal solves after hydraulics. No feedback to flow.

  • HEAT SOURCE/SINK — Machine that holds a leaving temperature. Use for chiller, boiler, cooling tower. Set leaving temperature and, if needed, setpoint control.
  • HEAT EXCHANGER — Machine that states a heat load. Use for AHU, FCU, plate exchanger. Set load (kW) and direction (heat/cool). Flow carries the heat.

Sign rule: −Q removes heat from fluid (cooling). +Q adds heat to fluid (heating). A CHW coil is +Q to the fluid? No — check sign switch on the panel. Heating is red, cooling is blue.

3.5 DESIGN > Valves outlined

EditSELECTCOPYPASTE PipePIPERISER HydraulicSOURCEOUTFLOWPUMPOTHER ThermalHEAT SOURCE/SINKHEAT EXCHANGER ValvesCONTROLISOLATIONCHECK

Valves — control flow.

  • CONTROL (globe) — Modulating valve. The only valve a controller can drive. Set Kv and opening (%). Opening follows a sensor in SIMULATE.
  • ISOLATION (gate) — Open or closed only. Not for regulation. Use to isolate a branch.
  • CHECK (non-return) — Flow in one direction only. Prevents back flow. The app shows flow direction on the pipe.

3.6 Other DESIGN modes — bottom ribbon changes

Bottom ribbon is not always DESIGN. Switch MODE on the top row to see other tool sets.

CONTROL mode

SensorsTEMPERATUREFLOWPRESSUREDIFF. PRESSUREDIFF. TEMPERATURE ControlsADD CONTROL ValveCONTROLISOLATIONCHECK
  • TEMPERATURE / FLOW / PRESSURE — Place a sensor on a pipe. The sensor reads that quantity.
  • DIFF. PRESSURE / DIFF. TEMPERATURE — Differential sensor. Click first pipe, then second pipe. Reads difference between the two.
  • ADD CONTROL — Link a pump or control valve to a sensor or equipment. Click actuator, then sensor. Set setpoint on the sensor panel.

SIMULATE mode

ModeSTATICDYNAMIC RunRUN SIMULATION InspectSELECTPROBE
  • STATIC — Lock the drawing. No auto-solve on edit. Use for large models. Click RUN SIMULATION to solve.
  • DYNAMIC — Solve on every edit. Use for small models. Response is immediate.
  • RUN SIMULATION — Solve now. Use in STATIC after you change something.
  • SELECT — Select and inspect. Read-only in STATIC.
  • PROBE — Read pressure, flow, velocity at any point on a pipe. Click to pin. Press Esc to clear.

ANNOTATION mode

ArrangeMOVETRACEALIGNDISPLAY TAGS DrawDETAILTEXT BOX Link nodesADDREMOVE
  • MOVE — Move labels, tags, notes, detail lines, link nodes. Drag to place for print. Offsets store in screen pixels, so they stay correct at all zoom levels.
  • TRACE — Place a background image. Paste or drag in a drawing. Calibrate scale. Trace over it.
  • ALIGN — Move the whole model. Drag any node to shift all floors together. Use to align to grid.
  • DISPLAY TAGS — Choose what the drawing shows (diameter, length, flow, pressure, etc.).
  • DETAIL — Draw free lines. Not part of the model. Use for room outlines, plant boxes, leaders. Click to add vertices, Esc to finish. Click existing line to erase.
  • TEXT BOX — Place a free text note on the drawing.
  • ADD / REMOVE (Link nodes) — Add or remove a bend on a control link or ΔP route.

4. Next steps

  • Calculation tab — read results, print the sheet, export CSV.
  • Hydraulic tab — set fluid, method, fittings, schedules, limits.
  • Thermal tab — set ambient, insulation, plausibility band, read energy balance.
SUGGESTION:

Start small. Draw source → pipe → outflow (1 L/s, 100 kPa). Solve. Check pressure at the outflow. Then add a pump on Auto. The app will size it to meet the terminal. This loop teaches DESIGN before you add loops, valves, or control.
