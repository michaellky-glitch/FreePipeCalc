Tutorial — Hydronic — Calculation

How to read the CALCULATION tab. Top ribbon reference and sheet guide.

Hydronic discipline · CALCULATION tab · v0.18.2

CALCULATION shows the result. Each pipe is one row. Pressure, flow, velocity, and head loss are on that row. Index circuit comes first. Warnings are at the end. Collapse sections to control what prints.

NOTE:

Click CALCULATION in the top bar to open this tab. The drawing toolbar hides. The sheet appears. Top ribbon still exists but is hidden on this tab — the mock-ups below show it as it appears on PIPING NETWORK, for reference.

1. Overview

Three layers:

  • Header — project data (project, system, engineer, date). Edit on the sheet. Saved with the model.
  • Sections — collapsible blocks. Each block is one table or one warning group.
  • Totals and disclaimer — sums and the verification note. Always at the end.

Index circuit first (sets pump duty). Other branches after. Use background tint to find index rows.

How to read the sheet:

  • Header — Edit project fields here. The sheet records method and fluid for traceability.
  • Critical path (index) — Path from source to the worst-served outflow. Its total loss sets the pump duty. Listed first, tinted green.
  • All sections — One row per pipe. Columns: tag, size, bore, length, fittings, flow, velocity, pressure drop, friction rate (Pa/m), static head, outlet pressure.
  • Warnings — At the end, grouped as Defect / Warning / Notice. Defect = drawing is wrong. Warning = value over limit. Click message chip or MESSAGES window to find the item.
  • Collapse — Click a section header to collapse it. Collapsed sections do not print. Use this to control the issued set.
  • Disclaimer — At the end of every sheet. Do not remove it. Results need independent check by a qualified engineer.
IMPORTANT:

Sheet values use display units from SETTINGS. Change units there — the sheet updates. SI is still the stored value.

5. Sheet actions

SAVE CALCULATION (CSV) SAVE MODEL PRINT

Actions on this tab:

  • SAVE CALCULATION (CSV) — Export sheet tables as CSV. UTF-8 with BOM, so Excel reads symbols. One file per table when needed (e.g., wide plumbing sheet).
  • SAVE MODEL — Save the model file. Same as FILE > SAVE. Do this after you edit the header.
  • PRINT — Print the sheet. The app picks portrait or landscape by table width. Collapsed sections stay hidden on paper.
SUGGESTION:

Check the status chip first. Green = solved. Number + grey = warnings. Red = error. Click the chip to open MESSAGES. Fix defects before you issue the sheet.
