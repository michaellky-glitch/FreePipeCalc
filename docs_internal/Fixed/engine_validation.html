1. Overview

A source feeds a pump. The pump feeds a ring. Three outflows sit on one side of the ring, each drawing 1 L/s at 100 kPa minimum. All pipe is DN50, C = 120.

This page reproduces the worked example from docs/engine.html §6.3. Every claimed value is independently recomputed. The additional material here derives the flow-split equations that the GGA solver handles.

Final answers match the doc to the stated precision. Intermediate values are carried to six figures.

4. Fitting classification

Fittings are inferred from the geometry at each node. The engine uses a two-pass classifier:

  1. Pass 1 (geometric guess): At each node, the code counts pipes meeting and their angles. Pipes with deviation < 8° are straight-through and receive no fitting. Pipes at 90° get an elbow. Three-pipe nodes are classified as tees.

  2. Pass 2 (with converged flows): Actual flow directions determine which tee legs are run vs branch, and whether the tee is dividing or combining.

Tee at N1

Three pipes meet: P10 (from N8), P1 (to N2), P5 (to N5). P10 is horizontal. P1 and P5 are vertical, both at 90° to P10 and symmetric. The flow divides (P10 in, P1 and P5 out). Both outlets get TBRANCH_DIV (bullhead dividing tee, EL = 3.05 m).

Elbows at N2, N3, N5, N10

Two pipes meet at each node, at 90° → E90 (EL = 1.52 m).

No-fitting pipes

P8 and P10 are horizontal, collinear at N7/N8. P12 and P13 are vertical, collinear at N9/N6. The pump link (P9) has no fitting.

6. Junction Flow

The solver does not assume symmetry. It finds the split from the governing equations.

6.1 Equations

At every junction, flow in must equal flow out to satisfy conservation of mass. Along every pipe, the head drop equals the friction loss (energy).

Continuity at N1 QP10 + QP5 + QP1 = 0
Flow positive from "from" node to "to" node. P5 enters N1 from N5, so QP5 enters. P1 leaves N1 to N2, so QP1 leaves. P10 enters from N8.
Energy along the upper path (N1 → N6) H(N1) − H(N6) = hf(P1) + hf(P2) + hf(P11) + hf(P12)
  = r₁·|Q₁|n−1·Q₁ + r₂·|Q₂|n−1·Q₂ + r₁₁·|Q₁₁|n−1·Q₁₁ + r₁₂·|Q₁₂|n−1·Q₁₂
Energy along the lower path (N1 → N6) H(N1) − H(N6) = hf(P5) + hf(P4) + hf(P15) + hf(P13)
  = r₅·|Q₅|n−1·Q₅ + r₄·|Q₄|n−1·Q₄ + r₁₅·|Q₁₅|n−1·Q₁₅ + r₁₃·|Q₁₃|n−1·Q₁₃

Both paths share the same endpoints N1 and N6, so the left-hand sides are identical. The right-hand sides must therefore sum to the same value. This is the loop closure condition: the total head loss around any closed loop is zero.

6.2 Flow Ratio

After each outflow node removes its 1 L/s, the remaining flow on P12 and P13 is the same (0.5 L/s on each side), and the pipes are nearly identical in length and resistance. This means the upper and lower paths between N1 and N6 have the same total resistance.

Write Qupper for the flow leaving N1 toward N2, and Qlower for the flow leaving N1 toward N5. Continuity at N1 gives:

Qupper + Qlower = Qtotal = 3.0 L/s

Loop closure gives:

Loop closure hfupper(Qupper) − hflower(Qlower) = 0

For a single pipe, hf = r · Qn. Extending this to a chain of pipes in series, each carrying the same flow (because there are no intermediate outflows on the ring between N1 and the first outflow on each side), the total head loss is proportional to Qn:

hfpath = Rpath · Qn

where Rupper = r₁ + r₂ + r₁₁ + r₁₂,   Rlower = r₅ + r₄ + r₁₅ + r₁₃

Substituting into the loop equation:

Rupper · Quppern = Rlower · Qlowern

Qupper / Qlower = ( Rlower / Rupper )1/n

This is the general result: the flow ratio equals the resistance ratio raised to the power 1/n. For Hazen-Williams, n = 1.852, so:

Qupper / Qlower = ( Rlower / Rupper )0.5399

6.3 Numerical check

Step-by-step arithmetic. Each line carries the calculation forward.

  1. Path resistances — sum the pipe resistances along each path:

    Rupper = r₁ + r₂ + r₁₁ + r₁₂
      = 20 800.6 + 16 847.2 + 12 972.2 + 3 878.1
      = 54 498.1

    Rlower = r₅ + r₄ + r₁₅ + r₁₃
      = 20 800.6 + 16 847.2 + 12 968.2 + 3 875.9
      = 54 491.9

  2. Resistance ratio — how much more resistant the upper path is:

    Rlower / Rupper
      = 54 491.9 / 54 498.1
      = 0.999886

  3. Flow ratio — raise to the power 1/n = 0.5399:

    Qupper / Qlower = (Rlower / Rupper)1/n
      = 0.9998860.5399
      = 0.999939

  4. Solve for each flow — combine with Qupper + Qlower = 3.0:

    Let r = Qupper / Qlower = 0.999939

    Qupper = 3.0 × r / (1 + r)
      = 3.0 × 0.999939 / (1 + 0.999939)
      = 2.999817 / 1.999939
      = 1.49997 L/s

    Qlower = 3.0 / (1 + r)
      = 3.0 / 1.999939
      = 1.50003 L/s

  5. Compare with engine:

    Engine: Qupper = 1.499967 L/s    Qlower = 1.500033 L/s
    Hand: Qupper = 1.49997 L/s    Qlower = 1.50003 L/s

    Δ < 0.00001 L/s ✓
General case

If the ring were asymmetric — different pipe sizes, different fitting counts, or outflows at unequal positions — the ratio Rlower/Rupper would not be 1, and the flow split would not be 50/50. The solver handles this without special treatment: the Newton-Raphson iteration finds whatever Q values satisfy both continuity and energy simultaneously.
