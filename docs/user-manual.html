User Manual

How to use FreePipeCalc: the interface, the design tools, and every control.

The calculation methods are documented separately in Calculation Method. Current to v0.18.19.

1. Interface overview

The window has a top bar, a design pane, and a properties panel. This section describes each part.

1.1 Main ribbon

The tabs at the top of the window select the main view.

TabWhat it shows
HYDRONIC / PLUMBINGThe design pane. You draw the network here. The tab is named for the current discipline.
CALCULATIONThe calculation sheet: a node-to-node table of sizes, flows, friction and pressure.
HYDRAULICFluid properties, the friction method, the pipe schedule, fitting allowances and the warning limits. In plumbing it also holds the IPC tables.
THERMALAmbient temperature, insulation, and the temperature plausibility band. Hidden in plumbing.
SETTINGSDisplay units, the generated pump curve, drawing defaults, appearance, CSV options, and setpoint control.
DOCUMENTATIONThese documents.

1.2 Discipline chip

The chip on the right of the top bar shows the discipline: HYDRONIC or PLUMBING. Click it to switch. A file is one discipline.

IMPORTANT:

Switching discipline on a drawing that is not empty can break it. The two disciplines share the geometry but not the device meaning, so a switch can leave device settings that no longer apply. The program asks you to confirm first.

1.3 Notification chip

The chip beside the discipline chip reports the state of the calculation. It shows one of: solved, a warning count, a defect count, or a hydraulic error. Its colour follows the severity.

Click the chip to open the Messages window. The window lists the active messages and the dismissed ones. Click a message to go to the pipe or node it names. You can dismiss warnings and notices. You cannot dismiss errors or defects.

1.4 Levels

The Levels panel lists the floors. The active level is the one you draw on. Everything drawn on a level is horizontal at that level's elevation. A riser joins one level to another.

Add a level with + and remove the active level with −. Collapse the panel with the LEVELS heading; the active level is then shown on the heading. Drag a level to reorder it. Double-click a level to edit it.

ControlWhat it does
NameName of the level.
ElevationHeight of the level above the datum.
View DirectionLook Down or Look Up. This shows the level above or below the active level as a faded overlay, so you can see what you are connecting to.
NOTE:

View Direction also sets which way a new riser runs from this level. Look Up runs the riser to the level above; Look Down runs it to the level below.

1.5 Properties

The Properties panel shows the selected item. It has up to four collapsible sections:

  • Design — what you set: size, flow, capacity, and so on.
  • Actual — what the calculation returned: the solved flow, pressure and temperature.
  • Control — the control link, for a pump, a valve or a machine that carries one.
  • Display — which values are written beside the item on the drawing.

Each section remembers whether it is open or closed. A 🛈 marker holds a longer explanation where one is useful. Select nothing to see no panel; select several items to edit their common properties together.

2. Hydronic design

The design pane is where you draw and analyse a water network. This section describes the hydronic discipline. The plumbing discipline is in section 3.

Hydronic covers chilled water and process cooling systems. You draw the pipework and the plant, size it in Design, and then run it in Simulate.

2.1 File

The FILE group holds the common file actions.

ControlWhat it does
NEWStart an empty model.
SAVESave the model to a file (Ctrl+S).
LOADOpen a saved model file.
PRINTPrint the drawing. The program asks whether to print the level plans or the calculation sheet. Level plans print one page per level. The calculation sheet prints the open sections only, so you choose what to issue by collapsing the sections you do not need. The sheet turns to landscape by itself when its table is wider than a portrait page.
REPAIRFind and fix tags that have an automatically generated tag stuck on the end of them.
DXFExport the drawing as a DXF file. The program asks for one of two forms. The 3D model puts every level at its real height in one file. By Level writes one file per level and keeps the height ordinates, so the sheets still stack when referenced together. The export carries geometry and text only, not properties or reports. It is experimental; check that it opens in your CAD.
↶ / ↷Undo and redo (Ctrl+Z and Ctrl+Shift+Z).

Copying elements and properties

There are two kinds of copy.

Copy elements. Select one or more pipes and press COPY, or Ctrl+C. The copy holds the pipes, the nodes they touch, and the control links between them. Press PASTE, or Ctrl+V, and the copy follows the pointer. Click to place it. While placing, press Tab to choose which end joins the drawing, and R to rotate the copy by 90°. If you drop the copy on top of an existing pipe, the program splits that pipe and joins with a tee.

Copy properties. Copy a single device, then select one other device of the same kind and press Ctrl+V. The program stamps the copied device's properties onto the selected one. It does not copy the tag, the position or the control link. Use this to give several pumps, valves, coils or outflows the same settings.

2.3 Design

In Design you draw the pipework and the plant. Outflows state the flow they need; the program sizes the pump and reports the pressures.

IMPORTANT:

In Design mode the drawing annotations show the design flow and the design thermal properties.

Pipe

PIPE draws a horizontal pipe. Click to start, click to place each point. The bearing snaps to 15°. Hold Shift for free placement. Type a number and press Enter to set an exact length.

RISER draws a vertical pipe to the level in the view direction of the active level.

Control (Pipe)What it does
TagName of the pipe.
ScheduleThe pipe schedule, which sets the bore for each size.
SizeThe nominal pipe size.
C factorThe Hazen-Williams roughness coefficient for this pipe.
LengthThe drawn length. Changing it moves the far end.
InsulationInsulation thickness for this pipe. Blank uses the default; 0 is a bare pipe.

A riser has the same Schedule, Size and C factor controls. A riser's length comes from the level heights and cannot be set by hand.

Hydraulic

These tools place the parts that carry or draw water.

Source. Places a water source, such as a reservoir, city main or expansion tank. It sets the pressure at that point.

Control (Source)What it does
Static pressureThe gauge pressure the source holds at its own level.

Outflow. Places a water outlet that draws a stated flow at a stated pressure.

Control (Outflow)What it does
Design flowThe flow the outlet draws.
Design pressureThe pressure the outlet needs.
On/OffInclude the outlet in the calculation, or leave it out.
NOTE:

The design flow and design pressure set a K factor for the outlet, from Q = K·√P. Simulate uses that K factor to find the flow the outlet actually draws at the pressure it is given. Other equipment that states a flow and a pressure drop is treated the same way.

Pump. Places a pump. The Sizing control has three modes.

Sizing modeWhat it does
AutoIn Design, the program raises or lowers the head until the worst-served outflow has exactly its required pressure. The duty comes down as well as up.
ManualYou state the design flow and the design head. The program does not change them.
CurveYou enter the pump curve, from the manufacturer. Simulate reads the operating point from this curve.

The pump panel also has Design flow and Design pressure boxes, a Re-size button in Auto, and buttons to enter or generate a curve.

IMPORTANT:

A pump must be in Manual or Curve sizing mode to run in Simulate. An Auto pump has no fixed curve for the simulation to read.

To make a pump follow a sensor, link it to a differential-pressure sensor. There are two ways to do this: from the pump's Control section, or in Control mode with ADD CONTROL. In Simulate the program then adjusts the pump speed to hold the sensor setpoint.

SUGGESTION:

Sync a pump with the other pumps serving the same load. This holds them at a common speed and makes the simulation more stable.

Other. Places adiabatic equipment: pipework with a pressure drop and no thermal behaviour, such as a strainer, a filter or a flow meter.

Control (Other)What it does
FlowThe rated flow.
Pressure dropThe pressure drop at the rated flow. The drop follows the square of the flow away from the rating.

Equipment

IMPORTANT:

Heating and cooling capacity refer to adding or removing heat from the water. A chiller removes heat, so its work is cooling. An air handling unit adds heat to the water, so its work is heating.

Heat Source/Sink. A machine that holds a leaving water temperature: a cooling tower, a chiller or a boiler. It holds its setpoint up to the limit of its capacity.

Control (Heat Source/Sink)What it does
FlowThe rated flow through the machine.
Pressure dropThe pressure drop at the rated flow.
Cooling / HeatingWhether the machine removes or adds heat.
CapacityThe most heat the machine can move.
Design LWTThe leaving water temperature the machine tries to hold.
SUGGESTION:

Set the heat source or sink capacity by hand before you run Simulate, so the machine holds a realistic duty.

Heat Exchanger. A machine that states a load: an air handling unit, a fan coil unit or a plate heat exchanger. It holds a pressure drop, which holds its flow and its capacity. The temperature limit is the highest leaving water temperature it can reach; for a cooling coil this is the return air temperature less the coil approach.

Control (Heat Exchanger)What it does
FlowThe rated flow.
Pressure dropThe pressure drop at the rated flow.
Cooling / HeatingWhether the coil removes or adds heat.
CapacityThe design load.
Design ΔTThe design temperature difference across the coil.
Temperature limitThe highest leaving water temperature the coil can reach.
Control valveSet the built-in valve to Auto or Manual. Refer to the text below the table.
Valve position (%)The position of the built-in valve. You can set it only when the valve is Manual.
IMPORTANT:

Set the control valve to Auto to let the coil modulate itself. The valve then holds the design ΔT of the coil. Without a valve the coil gives the same heat at all flows, and ΔT control is not possible.

SUGGESTION:

Sync a coil with the other coils serving the same heat load. This makes the simulation more stable.

Valves

IMPORTANT:

Take the valve Kv from the manufacturer's data. The built-in value is derived, not measured.

NOTE:

The Kv at a partial opening is the full-open Kv multiplied by a factor from the valve's flow characteristic. A control valve uses an equal-percentage characteristic. An isolation valve uses a near-linear characteristic. The program interpolates between the tabulated positions of the characteristic.

ValveWhat it does
ControlA balancing and control valve, such as a globe valve or a PICV. A controller can drive it. Its Design section sets the Kv (or Cv) and its opening.
IsolationA gate or butterfly valve, open or shut. It is not for regulating. Its status is Open or Closed.
CheckA non-return valve. It permits flow in one direction only. Its position is not set by hand.

2.4 Control

In Control you place sensors and link them to pumps and valves.

Sensors

A sensor reads a quantity on the pipe it sits on, and holds a setpoint. The tools place five kinds.

SensorMeasures
TemperatureWater temperature at the sensor.
FlowFlow through the pipe.
PressureGauge pressure at the sensor.
Diff. PressurePressure difference between this pipe and a second pipe you pick.
Diff. TemperatureTemperature difference between this pipe and a second pipe you pick.

Each sensor has a setpoint box for the quantity it measures.

NOTE:

The control connection point is on the pipe, not on the differential-pressure indicator.

Add Control

ADD CONTROL links a sensor to equipment. Click the pump or control valve, then click the sensor or equipment it should follow.

NOTE:

Sensors can be linked to pumps and control valves. Heat sources, heat sinks and heat exchangers cannot modulate from a remote sensor. If you need to control from a sensor, connect a control valve to the sensor.

Valves

The valve tools are repeated here, so you can add a control valve without leaving Control mode. They are the same tools as in Design.

Setpoint limits

Each setpoint has a comparator. The comparator tells the controller when to act.

ComparatorWhat the controller does
SETHold the value. This is the default.
MINAct only when the reading is below the value. If the reading is above it, the device stays where it does least. A bypass valve stays closed.
MAXAct only when the reading is above the value.

Use MIN to hold a minimum flow through a chiller. Put a flow sensor on the chiller. Set the flow setpoint to the minimum flow of the chiller, and set the comparator to MIN. Then link the bypass valve to the sensor.

The bypass valve stays closed while the flow is above the minimum. When the coils close and the flow falls, the valve opens. It opens only as much as it must.

IMPORTANT:

Do not use SET for a minimum flow. SET tries to make the flow equal to the value. When the system is busy the valve cannot decrease the flow to that value. The program then reports a lost setpoint and opens the valve fully.

2.5 Simulate

In Simulate the program solves the system in steady state. Terminals become resistances, pumps read their curves, and controllers modulate.

IMPORTANT:

In Simulate mode the drawing annotations show the stabilized flow and the stabilized thermal properties.

ControlWhat it does
StaticFreezes the simulation. Nothing re-solves while you look at it, which keeps a large model responsive.
DynamicRe-runs the simulation every time you make a change.
Run SimulationRe-solve the model now. Use this in Static after you change something.
SelectSelect any element to read its simulated properties.
ProbeRead pressure, flow and velocity at any point along a pipe. Click to pin the reading; press Esc to clear it.

2.6 Calculation sheet and the critical path

The CALCULATION tab shows the calculation sheet. The sheet has two main sections. All Pipes lists every pipe. Critical Path lists only the pipes on the circuit that sets the pump duty.

The heading of each section shows the mode you solved in: Design or Simulation.

The automatic path

The program finds the critical path for you. In a closed system it looks for the circuit that uses the most head to reach its equipment. Every circuit through the pump loses the same total head, so the program compares the head that is left across each machine. The machine with the least head left is the one that is most difficult to reach.

In an open system the program looks for the outflow with the least residual pressure.

The manual path

You can select the two ends of the path yourself. Do the steps that follow.

  1. Go to the CALCULATION tab.
  2. In the Critical Path section, click [Manual]. The program shows the HYDRONIC tab.
  3. Click the first node.
  4. Click the second node. One of the two nodes must be on a pump.

The program then calculates the friction between the two nodes and back to the pump. The section note changes from Auto to Manual.

To go back to the automatic path, click [Auto]. You can also press Esc during the selection.

NOTE:

One of the two nodes must be on a pump. A friction total is only correct as a circuit: out along the run, and back to the machine that moves the water.

SUGGESTION:

Use the manual path to check a result by hand. Select a run you know, then compare the total on the sheet with your own calculation.

Click CAL PATH in the SHOW group to see the path on the drawing. The program draws the path in red. This shows the automatic path or the manual path, whichever the sheet reports.

3. Plumbing discipline

The plumbing discipline sizes domestic cold and hot water from fixture units, using the IPC method. This section describes only what differs from hydronic.

Switch to plumbing with the discipline chip. A plumbing file uses fixture units, not a flow balance, so the network solver is not used to size it.

Tabs and tools

  • The network tab is named PLUMBING.
  • The THERMAL tab is hidden. There is no thermal calculation in a plumbing file.
  • The Design ribbon has no Heat Source/Sink or Heat Exchanger. Domestic water has no thermal plant.
  • The HYDRAULIC tab adds the IPC tables: the fixture-unit table, the demand curves, and the Table 604.3 fixture flows and pressures. It keeps the fluid properties, the friction method, the pipe schedule, the fitting allowances and the warning limits.

Outflows are fixtures

In a plumbing file an outflow is a plumbing fixture, not a stated flow. Its properties are different.

Control (plumbing outflow)What it does
Outflow typePlumbing fixture, or a generic outflow with a stated flow.
FixtureThe fixture, from the IPC table.
VariationThe occupancy and supply control for that fixture.
CountHow many of the fixture are at this outlet.
On/OffInclude the outlet, or leave it out.

The panel also shows the fixture units, the design flow and the design pressure that the IPC tables give for the fixture.

Sizing and simulation

  • Design sizes each pipe from the fixture units downstream of it, through the demand curve. A generic outflow adds its flow on top, without diversity.
  • A plumbing network must be a tree: one source, no loops. The program reports a loop, a missing source or several sources, rather than estimating.
  • Simulate works the same way as hydronic. Each open fixture becomes a pressure-dependent terminal, so it draws more where the pressure is high and less where it is short. Switch fixtures On or Off to set the load case. A booster pump linked to a sensor holds its setpoint.
NOTE:

The HYDRAULIC tab has a maximum static pressure limit for plumbing. The program warns above it. A fixed-speed booster develops the most head at the lowest draw, so the highest pressure is usually at the quietest hour.
