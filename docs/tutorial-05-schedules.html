Tutorial 05: Adding a pipe schedule

Add a pipe material that the program does not include. You can do this in the app, or in the data file.

The file is data/schedules.js. Use any text editor to change it. The program has no build step.

1. Which way to add one

There are two ways to add a schedule. Each way has a different use.

QuestionIn the appIn the file
Where it livesIn the model file, and in this browserIn the program
Who gets itAnyone you send the model toAnyone you send the program to
Survives a new copy of the programYes, it is in the modelNo, you copy the file across
Available in every new modelNoYes
Needs a text editorNoYes
SUGGESTION:

Use the app if you must add a schedule for one model. Use the file if your office uses the material on all models. Copper is an example, because the program does not include it.

2. The in-app way

You do not have to change a file to add a schedule for one model.

  1. Open the HYDRAULIC tab.
  2. Press Copy Current Schedule to start with the sizes of the schedule on display. Press Add schedule to start with an empty schedule.
  3. Paste your size table. The columns are the label, the bore in mm, and the outside diameter in mm. The program accepts tabs, commas, semicolons and spaced columns. Thus you can paste directly from a spreadsheet.
  4. The program ignores a heading row. If the program cannot read a line, it tells you. It does not remove the line without a message.

The program saves the schedule in the model. The schedule goes with the file to other users. The remainder of this tutorial shows the other way.

3. The file way

Open data/schedules.js in any text editor. The file is plain JavaScript. The program reads the file as it is. You do not compile it.

IMPORTANT:

Make a copy of the file before you change it. If one comma or one bracket is missing, the program does not start. The window is then empty.

4. What a schedule is

A schedule is a name, a default C factor, and a list of sizes.

FieldWhat it is
keyThe short name in quotes, such as 'sch40'. A saved model records this, so choose it once and do not change it later.
nameWhat the user sees in the schedule list.
defaultCThe Hazen-Williams C factor a new model starts with for this material. About 120 for steel and about 150 for plastic and copper.
sizesThe list of pipe sizes.

Each size carries three things.

FieldWhat it is
labelThe nominal designation, such as DN50 or 110 mm. It is a name, not a dimension.
id_mmThe bore, in millimetres. The friction calculation uses this value. No other value changes the friction. Make sure that it is correct.
od_mmThe outside diameter, in millimetres. The thermal module uses it for the insulation surface area.
NOTE:

The nominal label and the bore are different numbers. HDPE “110 mm” is an outside diameter with a bore near 90 mm. The program looks fittings up on the label and calculates friction on the bore, so both must be right.

You do not have to work the bore out yourself. Two helpers accept whichever form your published table is printed in:

fromWall([ [label, outside diameter, wall thickness], … ])
fromBore([ [label, bore, outside diameter], … ])

fromWall derives the bore as od − 2 × wall, which is how nearly every pipe table is printed. fromBore takes the bore directly; its outside diameter is optional.

IMPORTANT:

If you do not give the outside diameter, the program uses the bore in its place. The pipe is then too small in the thermal calculation. The area of the insulation is too small, and the calculated heat loss is too low. Give the outside diameter if you know it.

5. Add your schedule

Find the block YOUR OWN SCHEDULES at the end of the SCHEDULES table. The block contains two templates.

  1. Copy the template block.
  2. Remove the /* and */ that comment it out.
  3. Put a comma after the closing brace of the entry above yours, or the file will not load.
  4. Replace each placeholder with a value from your published table. The placeholders are <od> and <wall>. They are not numbers. Thus the program stops immediately if you forget to replace them. This prevents the use of incorrect pipe data.
  5. Choose your key and your name.
  6. Save the file.

A completed schedule has this form. Use your own values:

,'copper_x': {
  name: 'Copper EN 1057 X',
  defaultC: 150,
  sizes: fromWall([
    // [ label, outside diameter mm, wall thickness mm ]
    ['15 mm', 15.00, 0.70],
    ['22 mm', 22.00, 0.90]
  ])
}
IMPORTANT:

The two rows above show the form of a schedule. They are not copper data. Take each dimension from the published standard for your pipe.

6. Make the change appear

Save the file. Then reload the program. If your schedule is not in the list, the browser uses the copy that it kept.

Each script in index.html carries a version token:

<script src="data/schedules.js?v=0.18.10"></script>

The browser keeps a file that has the same token. Change the number at the end of that line. Then reload the program. The browser then reads your changed file.

IMPORTANT:

This is the usual cause when a change has no effect. Examine the token before you examine your change. A hard reload also reads the changed file one time. To do a hard reload, press Ctrl+Shift+R.

7. Check your work

  1. Open the HYDRAULIC tab. Your schedule is in the Current schedule list, under the name you gave it.
  2. Select it. The table below shows every size with its bore, outside diameter and wall.
  3. Compare the bore with your source table. The friction calculation uses this value.
  4. Draw one pipe. Give the pipe a flow. Then read the velocity on the calculation sheet. The program calculates the velocity from the bore. If the velocity is incorrect, the bore is incorrect.
SUGGESTION:

Examine the largest size and the smallest size. Do not examine only a size in the middle. If a column is one row out of position, you see this most easily at the two ends.

8. When it goes wrong

What you seeWhat it usually is
The window opens blankThe file has a syntax error. A comma between two schedules is missing, or a bracket is not closed. Use your copy of the file. Then make the change again in smaller steps.
Your schedule is not in the listThe cached file. Change the ?v= token, see step 6.
The placeholders are still thereYou removed the comment characters, but you did not replace the placeholders. The template stops the program for this reason.
An old model picks the wrong scheduleYou changed the key. If a model has a key that does not exist, the program uses Schedule 40 in its place. It does not give a message. Use the old key again.
Friction looks wrong for the sizeYou put a nominal label in the bore. These are different values. Refer to step 4.
Heat loss looks lowThe outside diameter is missing. The program used the bore in its place.

9. Where the numbers come from

Use the published standard for your pipe. The program includes ASME Schedule 10, 40 and 80, EN 10255 Medium and Heavy, PPR to EN ISO 15874, and HDPE PE100 to EN 12201. It does not include copper. Copper is thus the usual first addition.

IMPORTANT:

Do not estimate a dimension that you cannot find. Do not calculate a dimension from a size near to it. The program cannot identify an incorrect row. It calculates a result from that row in the usual way, and the sheet does not show a warning. If you cannot find a value, do not include the size.

NOTE:

A schedule that you add is your data. This program does not verify it. Examine the schedule before you issue a calculation that uses it.
